## Who am I?

I’m Kethan VR — a **Full-Stack AI & DevOps Engineer** who doesn’t just build apps, but architects, containerizes, deploys, and scales them end-to-end.

Most devs write code. I write code, ship it on my own VPS, set up the reverse proxy, automate the CI/CD pipeline, and integrate AI that actually works in production — not just demos.

**Right now, I’m:**

- 🧱 Building full-stack platforms used by thousands of students at CMRIT
- 🤖 Working with LLMs, fine-tuning models & building AI agents
- ⚙️ Self-hosting on DigitalOcean with Docker, Traefik & GitHub Actions pipelines
- 🚀 Turning real-world problems into production-ready solutions

**Philosophy:** Build with purpose. Ship with confidence. Never stop learning. And yes — debugging is literally my cardio 🕵️‍♂️

## Featured Projects

*Production-ready. Self-hosted. AI-powered. End-to-end.*

### 🎓 **[CMRIT Events Hub](https://cmrit-events.vercel.app)** — The “LinkedIn for Campus”

A full-stack platform revolutionizing campus life — verifiable student profiles, QR-code attendance, XP leaderboards, and club dashboards. Used by thousands of students at CMRIT.

*Next.js 16 · React 19 · Supabase · Tailwind CSS · Shadcn UI · TanStack Query*

-----

### 📚 **[Academic Material Portal](https://ise-study-material.vercel.app)** — Your study hub, simplified

Replaced scattered Drive links with a unified platform for lecture notes, syllabus, and question banks. Smart previews, instant downloads, PWA offline support.

*Next.js 16 · TypeScript · Tailwind CSS · Shadcn UI · Real-time Architecture*

-----

### 💊 **[MediScan](https://download-mediscan.vercel.app)** — Identify medicines from photos

Mobile-first AI web app that identifies medicines using your camera. Provides usage, dosage, side effects, chatbot support, scan history, and offline support via Gemini API.

*Next.js · Gemini API · Supabase · Tailwind CSS · PWA*
